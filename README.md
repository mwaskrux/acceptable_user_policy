This repository contains two versions of an Acceptable Use Policy (AUP) designed for a healthcare facility and aligned with ISO/IEC 27001:2022 Annex A controls, including A.5 (Organizational Controls), A.6 (People Controls), and A.8 (Technological Controls).

The AUP helps ensure secure and responsible use of hospital information systems, patient data, and IT assets.

This project is designed to help organizations:
-Establish acceptable use requirements.
-Support ISO 27001:2022 compliance documentation.
-Improve staff awareness and minimize risks related to data misuse.
-Standardize IT governance processes for healthcare environments.

This AUP aligns with the following ISO 27001:2022 Annex A controls:

A.5.10 – Acceptable Use of Information and Assets
A.5.11 – Return of Assets
A.6.2 – Information Security Awareness, Education, and Training
A.8.1 – User Access Provisioning
A.8.2 – Privileged Access Rights
A.8.9 – Use of Information and Systems
A.8.16 – Monitoring Activities
